## Problem
Non-technical team members couldn't query data without waiting days for a developer to run SQL reports.

## Solution & Flow
Ask questions on Telegram or Slack and get formatted answers, charts, and downloadable Excel reports instantly. No SQL required. Multiple LLM calls convert natural language into a safe SQL query, run it against Supabase, and return a formatted answer along with a downloadable Excel report.

## Tech Stack
Supabase, PostgreSQL, LLM, Telegram
